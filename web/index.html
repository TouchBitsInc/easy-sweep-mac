What it finds

Where the space actually went.

Each section opens with a bar splitting your disk by what is really there, largest first — so a glance tells you whether it is worth opening.

Applications

Uninstall an app and the caches, containers, preferences and launch agents it leaves behind. All of it goes to the Trash, so a guess is reversible.

Developer

Derived Data, device support, simulator devices and package caches for every toolchain you ever installed. Simulators are usually the biggest thing you own.

AI Tools

Claude Code, Codex, Cursor, Windsurf, Gemini CLI, Ollama, LM Studio. Caches and model weights other cleaners have never heard of. Credentials are never listed.

Browsers

Page and script caches for Chrome, Safari, Firefox, Edge, Brave and Arc. History, passwords, bookmarks and open tabs live elsewhere and are never touched.

Creative

Premiere and Media Encoder media caches, After Effects disk cache, Photoshop scratch, Camera Raw previews, Ableton decoding. Working caches only — never exports.

System

macOS’s own regenerable data — aerial wallpapers, Music artwork, user logs — plus the web and code caches every Electron app keeps beside its data.

Safety & privacy

A cleaner earns trust by what it refuses to do.

These aren’t settings. They’re enforced in the app’s own model and pinned by its test suite, so rearranging the interface cannot widen what a button reaches.

Nothing is pre-selected

Every checkbox starts empty, and each section’s button cleans only that section.

Irreversible items are marked

Archives, simulator devices and session history are flagged and excluded from every automatic path.

Uninstalls go to the Trash

A name match is a guess, and a guess must be reversible — so it reports “moved to the Trash”, never “freed”.

Failures are reported

A folder it cannot read is a failure with a pointer to Full Disk Access, never an empty folder with nothing to clean.

No account, no tracking

No telemetry, no crash reporter, nothing to opt out of. The free app never opens a network connection at all.

The catalogue is public

Every path it touches is on GitHub under MIT — checkable rather than promised, and open to additions.
