모든 앱의 캐시

모든 캐시를 하나의 목록으로.

브라우저, 편집기, 채팅 앱, AI 도구까지 앱별로 묶고 바이트 단위로 크기를 표시합니다. 개발자 데이터, 앱 잔여 파일, macOS 자체의 불필요한 파일과 함께 확인하세요. 모든 항목은 작업 전에 측정되고 설명됩니다.

개요

디스크 전체를 한눈에. 안전, 균형, 완전 중에서 선택하면 섹션별로 무엇이 정리되는지 정확히 확인하고, 한 번의 클릭으로 정리할 수 있습니다.

캐시

모든 앱의 캐시를 앱별로 묶어 하나의 목록으로 보여 줍니다. 설치된 어떤 앱에도 속하지 않는 캐시는 따로 표시되며, 자동으로 선택되지 않습니다.

개발

Xcode Derived Data, 시뮬레이터, 기기 지원 파일, 런타임은 물론 패키지 관리자와 툴체인 캐시까지. 각각 따로 표시되므로 아직 필요한 것은 남겨 둘 수 있습니다.

앱 데이터

내려받은 AI 모델, 세션 기록, 첨부 파일처럼 저절로 되돌아오지 않는 데이터입니다. 표시가 붙으며, 직접 선택하지 않으면 정리되지 않습니다.

시스템

macOS가 다시 만들 수 있지만 어느새 조용히 쌓이는 로그, 충돌 보고서, 내려받은 배경화면, 업데이트 잔여 파일.

네 가지 보기 방식

모든 페이지를 목록, 타일, 트리맵, 링 중 하나로 표시하고, 저장 공간 막대는 기본 막대나 도트 매트릭스로 선택하세요.

제거 도구

앱을 완전히 제거하세요.

앱이 남긴 모든 캐시, 컨테이너, 환경설정을 찾아 근거와 함께 보여 주고, 앱과 함께 휴지통으로 이동합니다.

추측이 아닌 근거

잔여 파일은 일치 확실도에 따라 묶입니다. 앱 식별자로 일치한 파일은 선택되고, 이름으로 일치한 파일은 사용자의 확인을 기다립니다.

언제나 되돌릴 수 있음

모든 항목은 휴지통으로 이동하며, 실행 취소하면 원래 위치로 돌아갑니다.

공유 파일은 그대로

설치된 다른 앱(베타 버전이나 두 번째 사본)이 함께 사용하는 파일은 공유로 표시되며 절대 삭제되지 않습니다.

삭제된 앱의 잔여 파일

직접 휴지통으로 끌어다 놓은 앱도 파일을 남깁니다. EasySweep이 이를 찾아 주고, EasySweep 밖에서 앱이 삭제되면 알려 드립니다.

보호된 앱

Apple 앱을 포함해 절대 제거하면 안 되는 앱을 지정하면, 해당 앱은 통째로 제거가 거부됩니다.

크기순 정렬

설치된 모든 앱을 크기와 함께 보여 주므로 가장 큰 앱이 가장 먼저 보입니다.

유틸리티

공간을 낭비하는 파일을 찾아 보세요.

어떤 앱에도 속하지 않는 공간을 위한 도구입니다. 내 파일, 오래된 프로젝트, 잊고 있던 시작 항목. 스캔을 누르기 전에는 아무것도 검색하지 않으며, 제거한 항목은 휴지통으로 이동합니다.

크고 오래된 파일

몇 달 동안 열지 않은 큰 파일을 종류별로 묶어 보여 줍니다. 자동으로 선택되는 항목은 없습니다. 내 파일이니 결정은 직접 하세요.

중복 파일

이름이 아닌 내용으로 찾은, 바이트 단위로 동일한 사본입니다. 각 세트에서 하나는 항상 남습니다. 가장 오래된 것, 가장 최근 것, 또는 선호하는 폴더에 있는 것.

Finder 메타데이터

Finder가 열어 본 모든 폴더에 남기는 .DS_Store 파일을 한 번에 찾아 지웁니다.

프로젝트 캐시

프로젝트 안의 빌드 및 도구 캐시를, 어디서나 캐시를 뜻하는 이름으로 찾습니다. node_modules나 설정이 담긴 항목은 절대 포함하지 않습니다.

앱 업데이트

App Store, Homebrew, MacPorts 또는 앱 자체 업데이트 도구로 업데이트해야 하는 앱을 확인하고, 하나의 목록에서 업데이트하세요.

시작 항목

로그인할 때 열리는 항목과 백그라운드에서 실행되는 도우미를 확인하고, 설정한 적 없는 항목은 제거하세요.

자동 정리

한 번 설정하면, 알아서 관리됩니다.

무언가 너무 커지거나 여유 공간이 부족해지면 스스로 정리하는 규칙입니다. 안전한 항목만 무인으로 실행되며, 모든 실행은 기록됩니다.

항목마다 다른 조건

캐시가 자체 크기 한도를 넘거나 여유 공간이 선택한 수준 아래로 떨어지면 정리합니다. Mac 전체에 하나의 획일적인 규칙을 적용하지 않습니다.

최신 파일은 남기기

모두 삭제하거나, 하루·일주일·한 달보다 오래된 파일만 삭제하세요. 최근 작업은 그대로 둘 수 있습니다.

다시 생기는 항목만 자동 실행

규칙은 저절로 다시 생기는 항목에만 적용됩니다. 아카이브, 세션 기록, 시뮬레이터 기기는 규칙과 관계없이 항상 수동으로 처리됩니다.

사용 중인 앱이 있으면 대기

관련 앱이 실행 중이면 무인 정리는 파일을 지우지 않고 기다립니다.

메뉴 막대에서 실행

자동 정리 버튼을 메뉴 막대에 추가하면 창을 열지 않고도 필요할 때 규칙을 실행할 수 있습니다.

모든 Mac에서 동일하게

규칙과 카테고리가 iCloud로 동기화되어, 사용하는 모든 Mac에서 같은 설정을 유지합니다.

사용자 지정 카테고리

나만의 카테고리.

다운로드, 프로젝트, 계속 커지는 그 폴더. 카테고리로 만들고 무엇을 지울지 선택하세요.

전용 페이지

각 카테고리에는 사이드바 행, 총량, 저장 공간 막대, 정리 버튼이 따로 생기며 기본 섹션과 동일하게 측정됩니다.

이름으로, 어떤 깊이든 정리

프로젝트 폴더 아래의 모든 빌드 또는 캐시 폴더를 이름으로 선택하거나, 실제 폴더 트리에서 직접 폴더를 고르세요.

직접 지정하는 단계

직접 단계를 지정하기 전에는 내 폴더가 안전, 균형, 완전 어느 단계에서도 선택되지 않습니다.

다크 모드와 Liquid Glass

나만의 스타일로.

라이트 또는 다크의 Liquid Glass, 도트 매트릭스 막대, 그리고 모든 페이지를 목록, 타일, 트리맵, 링으로.

Liquid Glass

데스크탑이 비쳐 보이는 반투명 윈도우.

라이트 또는 다크

시스템 설정을 따르거나, macOS 설정과 관계없이 EasySweep을 라이트 또는 다크로 고정하세요.

나만의 디스크 보기

정리하는 모든 페이지를 목록, 타일, 트리맵, 링으로 표시하고, 저장 공간 막대는 점 행으로 표시하세요.

활동

되찾은 모든 기가바이트를 확인하세요.

수동이든 자동이든 모든 정리의 용량, 시간, 위치와 모든 앱 업데이트를 하나의 기록으로 보여 줍니다.

시스템 모니터

내 Mac을 한눈에.

여유 공간, CPU, 메모리, 디스크 활동을 창에서 실시간으로, 그리고 메뉴 막대에서는 원하는 위젯으로 확인하세요.

메뉴 막대 위젯

여유 공간, CPU, GPU, 메모리, 네트워크, 디스크 활동, 배터리를 원하는 순서로 화면 상단에 고정하세요.

직접 구성하는 메뉴

메뉴 막대 드롭다운의 카드를 여유 공간부터 시스템 상태까지 선택하고 정렬하세요. 자동 정리 버튼도 추가할 수 있습니다.

실시간 차트

프로세서, GPU, 메모리, 네트워크, 디스크 활동을 2초마다 업데이트하며, 메모리 압력은 활성 상태 보기와 동일한 기준으로 표시합니다.

공간이 부족해지기 전에 대응

최소 여유 공간 수준을 선택하면, 디스크가 가득 차서 작업이 중단되기 전에 EasySweep이 알려 줍니다.

사용하는 모든 디스크

외장 디스크와 다른 내장 디스크가 시동 디스크 옆에 표시되며, 각각 공간을 차지하는 폴더를 열어 볼 수 있습니다.

보지 않을 때는 조용히

백그라운드에서는 아무것도 수집하지 않습니다. 모니터는 해당 페이지나 메뉴가 열려 있는 동안에만 Mac의 정보를 읽습니다.

직접 확인할 수 있는 안전

약속이 아닌 설계로 신중하게.

EasySweep은 삭제하는 순간 다시 확인하고, 확실한 것과 추측을 구분하며, 접근할 수 없는 항목은 알려 줍니다. 이러한 보호 장치는 정리 엔진 안에 있으므로, 버튼이나 자동화 규칙이 몰래 우회할 수 없습니다.

삭제 전 재확인

정리를 시작할 때 모든 위치를 다시 검증합니다. 경로가 바뀌었거나 예상치 못한 곳을 가리키면 EasySweep이 거부합니다.

위험한 항목은 선택하지 않음

섹션 페이지는 아무것도 선택되지 않은 상태로, 개요는 안전만 선택된 상태로 열립니다. 저절로 되돌아오지 않는 항목은 직접 클릭할 때까지 기다립니다.

중요한 곳은 되돌릴 수 있게

제거한 앱, 중복 파일, 유틸리티가 찾은 모든 항목은 휴지통으로 이동하므로 되돌릴 방법이 있습니다.

접근 권한에 솔직하게

EasySweep이 폴더를 읽을 수 없으면 아무것도 없는 척하지 않고, 그 사실과 접근 권한을 허용하는 방법을 알려 줍니다.

믿을 수 있는 크기

크기는 실제로 사용 중인 디스크 공간이므로, 표시되는 수치가 정리로 돌려받는 공간입니다.

설계부터 개인정보 보호

원격 분석, 충돌 보고, 백그라운드 데이터 수집이 없습니다. EasySweep은 사용자나 Mac에 관한 정보를 수집하거나 전송하지 않습니다.
